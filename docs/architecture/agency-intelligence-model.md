# Agency Intelligence Model — Intake Template (FULL-SERVICE CANONICAL)

Canonical lifecycle (locked): Lead → Pitch → Scope → Client → Brief → Strategy → Creative → Production → Approval → Launch → Media/Distribution → Performance → Learning → Retainer/Growth.
Specialist modes are overlays, never forks. Every finding below must name its mapping target or stay research.

## How to fill
For each section: finding → evidence/source → mapping target (one or more):
`graph object | workflow | screen | agent behavior | automation | governance rule | metric`.
No target = not architecture yet. Keep seams explicit (handoffs fail at discipline boundaries).
