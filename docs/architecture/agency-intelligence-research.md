# Agency Intelligence & Workplace Research (CANONICAL INPUT — north star locked)

North star (locked): AGENCY OS is the institutional memory, operating environment, intelligence layer,
execution system and governance fabric of an agency — the agency itself, represented as software.
Not Monday+ChatGPT+CRM+DAM. Full-service canonical; specialist modes are overlays.
Departments are views. One graph, one identity, one authorization, one evidence, one action, one memory.

Sources: IPA role descriptions (Account Manager as cross-functional bridge; planners translate
business/consumer research into briefs and evaluate creative; Creative Directors govern quality/brand;
Creative Services/Producers coordinate resources/timing/budget; media planners derive channel strategy),
Teamwork agency-operations evidence (69% time in meetings; 52% miss >50% billable utilization; scope
creep/overservicing/scattered comms/resource conflicts as margin killers), Adobe (centralized
assets/feedback/approvals/versioning vs friction).

## 1. Agency as living network (conceptual model)
PEOPLE (depts, expertise, seniority, capacity, careers) + CLIENTS (accounts, brands, campaigns,
markets, stakeholders) + BUSINESS (revenue, margins, costs, scope, growth) → WORK
(Strategy/Creative/Production + Media/PR/Content) → RESULTS (performance → learning → knowledge → future work).
People/work/clients/knowledge are views over one Agency Graph, never separate databases.

## 2. Roles (depth over `Role=Manager`; each needs cockpit, not task board)
Executive (portfolio: what is happening, where to intervene) | Account (relationship→brief→scope→
timelines→approvals→revenue→growth; needs Account Cockpit) | Strategy/Planning/Intelligence
(business problem→market→consumer→culture→insight→strategy→opportunity→measurement; needs
Insight→Strategy→Creative traceability) | Creative (brief→interpretation→ideation→territories→
selection→development→internal review→presentation→revision→approval→production; art+copy partners;
asset must know concept + strategic proposition) | Creative Services/Production (execution
infrastructure: resource→skill→availability→task→asset→stage→vendor→cost→deadline) |
Media/Performance (audience→channel→budget→creative→launch→pacing→optimization→performance→learning;
creative+media linked, never isolated reporting) | PR (organization→narrative→audience→influencer→
message→distribution→reaction→reputation; relationship intelligence) | Content/Social
(strategy→editorial→calendar→brief→creation→review→approval→publication→community→performance→iteration) |
Commercial/Ops (revenue, cost, capacity, margin, scope, utilization, forecast, pipeline, risk).

## 3. Hidden jobs (role weights over UNDERSTAND/CREATE/COMMUNICATE/COORDINATE/DECIDE/REVIEW/REVISE/DOCUMENT/DELIVER/LEARN)

## 4. Native vocabulary as graph commands
"Brief this / route to creative / waiting on feedback / out of scope / another route / another round /
approved? / latest version? / who's on it? / capacity? / deadline? / brief changed / push through
production / sign-off / burn? / overservicing? / retainer left? / charge this? / what did we learn?" —
each resolves to graph traversal (e.g. White Point → active campaign → approved state → blockers →
latest asset → pending approvals → budget → performance), never chatbot-only.

## 5. Recurring problems (what the OS must kill)
Context fragmentation (email/WhatsApp/Slack/Drive/Figma/Adobe/sheets/notes/decks) → Context Pack.
Feedback fragmentation (which feedback is authoritative?) → single approval-gated feedback channel.
Scope creep/overservicing (margin erosion) → Scope Sentinel at request moment. Context switching
(small projects, reprioritization) → Traffic Brain. Approval latency (account→CD→client→brand→legal) →
approval SLA + escalation. Knowledge loss on exit → institutional memory (permissions leave, knowledge stays).

## 6. Surfaces (10 territories, access-profile gated)
MY DESK (personal cockpit) / WORK / CLIENTS / INTELLIGENCE / CREATIVE / DELIVERY / BUSINESS /
KNOWLEDGE / AI (workbench: agents+models+tools permitted by policy) / COMMAND (mgmt/analytics/access/governance/health/audit).
Role examples: Account (today/client health/next best action/AI partner flagging 4th revision out of scope);
Designer (work queue + creative context + brand-conflict flags); CD (campaigns at risk, quality scores,
capacity, judgement queue); CEO (revenue/AGI/utilization/pipeline, client health, delivery, people).

## 7. Mentor, skill graph, career (coach, not surveillance)
Mentor: grounded in actual work (e.g. 3 revisions w/o change request → 4.2 unplanned hrs → draft scope record;
briefs missing success metric → pattern + fix together). Skill graph: role/seniority/skills/tools/models/
certs/projects/clients/strengths/gaps/performance/preferences/capacity → team fit % + availability.
Career: observed work → skills → performance → training → mentorship → progression. Governance: operational
observability (status/delivery/capacity/deadlines/approvals/quality/workload/budget) YES; personal
surveillance (keystrokes/screens/private messages/webcam) NEVER — encode in Sovereign.

## 8. Knowledge engine (epistemic states — differentiator)
Facts ≠ Observations ≠ Interpretations ≠ Hypotheses ≠ Decisions ≠ Learnings ≠ Institutional knowledge.
Each carries state; promotion requires evidence + validation (Learning draft→validated→embedded already in
schema; extend typing to all seven). Cross-client reuse governed: reusable YES/NO + applicability +
confidence, never leaking confidential strategy/pricing/data/research (Sovereign contamination guard).

## 9. High-value features (build order by enterprise value)
1. Scope Sentinel (request vs approved scope → hours/budget/margin impact → Change Request at the moment).
2. Brief Doctor (completeness/clarity/scope/measurement scoring + conflicts vs brand strategy, before costly work).
3. Context Pack (campaign truth bundle killing fragmentation).
4. Meeting Intelligence (transcript → topics → candidate decisions → human confirmation → canonical decisions/tasks/scope/risks/sentiment/graph updates; transcript ≠ truth).
5. Traffic Brain (incoming → classification → urgency → skills → priority → revenue → deadline → deps → capacity → optimal assignment).
6. Case Study Generator + Portfolio Intelligence (live DB: client/industry/problem/insight/idea/channels/outcome/team/capabilities, graph queries).
7. WorkObject lineage ("why does this exist?" answered: client→…→learning chain per asset).
8. Agent marketplace internal-first (agency agents inheriting identity/role/scopes/tools/models/budget/constraints).
9. AI Productivity Intelligence (role-aware: output/quality/impact/efficiency/collaboration/reliability/learning — never task-count for creatives).
10. WorkObject abstraction (Brief/Insight/Strategy/Concept/Script/Copy/Design/Asset/MediaPlan/PR/ProductionPlan/Proposal/CaseStudy/Report/Learning/Decision — owner, contributors, client, campaign, dept, status, version, parent/children/deps, evidence, feedback, approvals, cost, time, AI usage, tools, decisions, learning).

## 10. Five loops (AURORA coordinates)
Work (Brief→Work→Review→Approval→Delivery) | Client (Need→Communication→Response→Decision→Relationship) |
Intelligence (Observation→Insight→Strategy→Decision) | Business (Scope→Resource→Cost→Revenue→Margin) |
Learning (Result→Evaluation→Learning→Knowledge→Future Work).
Agent outputs are WorkObjects with rationale/evidence/context/model/prompt-hash/cost/version/confidence/compliance/approval-state — never chat text.
